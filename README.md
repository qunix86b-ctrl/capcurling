# CapCurling

한 화면에서 1~20명이 번갈아 플레이하는 병뚜껑 컬링 게임입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도 패키지 설치가 필요하지 않습니다. 웹 폰트를 불러올 수 없으면 기본 글꼴로 실행됩니다.

개발용 서버: `python -m http.server 8000`

브라우저에서 `http://localhost:8000`을 여세요. 모바일은 동일한 Wi-Fi에서 PC의 로컬 IP 주소와 포트 8000으로 접속할 수 있습니다(PC 방화벽의 허용 여부에 따라 달라집니다).

## Firebase Hosting 배포

기본 Firebase 프로젝트는 `capcurling`입니다. `firebase deploy --only hosting`으로 배포하며 공개 주소는 `https://capcurling.web.app`입니다.

## 조작 및 판정

- 필드 위 초기 설정에서 선수 수 선택 → 게임 시작 → 출발 구역의 위치 선택.
- 필드 어디든 누른 채 화살표를 보다가 손을 떼면 방향 확정.
- 필드를 다시 누르고 원하는 세기에서 손을 떼면 발사. 스페이스바도 지원.
- 26m 테이블, 고정 기준 원점으로부터 8m 이상 전진하면 기록 인정.
- 경계를 벗어난 병뚜껑은 즉시 리타이어하며 기준선 미달 여부는 모든 투구가 끝난 뒤 판정.
- 기준선에 미달한 병뚜껑도 정지 위치에 남아 충돌하며, 다른 병뚜껑에 밀려 기준선을 넘으면 기록 인정.
- 최종 위치가 가장 먼 생존 선수 우승. 0.01m 단위로 같은 기록은 공동 우승.
- 경기장은 화면 전체를 사용하며 선수마다 세 번의 필드 조작으로 진행합니다. 샷이 멈추면 1.2초 안내 후 다음 선수로 자동 전환됩니다.
- 경기 중에는 선수 패널 없이 필드에서 진행합니다. 종료 후 병뚜껑 모양, 최종 순위와 거리를 보여주고 리타이어 선수와 사유는 아래에 따로 표시합니다. 결과는 유지되며 재시작 버튼으로만 새 게임을 설정합니다.
- 전체 레인 보기, 다시 시작, 모바일 반응형 화면 지원.

## 검증

`node --test tests/physics.test.js`

마찰에 따른 정지 거리, 약한 샷, 경계 이탈, 충돌에 의한 이동과 탈락, 순위 및 기준선 경계를 검증합니다.

## 파일

- `index.html`: 화면 및 플레이 가이드
- `style.css`: 데스크톱/모바일 레이아웃
- `game.js`: 입력, 턴 진행, 카메라, Canvas 렌더링
- `physics.js`: 고정 시간 간격의 마찰/충돌 계산 및 판정
- `guide.html`: 게임 방법 및 상세 규칙
- `about.html`: 게임 소개와 그래픽·상표 안내
- `privacy.html`: 현재 데이터 처리와 광고 도입을 반영한 개인정보처리방침
- `terms.html`: 서비스 이용약관
- `contact.html`: 운영자 및 문의 안내
- `info.css`: 정보 페이지 공통 반응형 디자인
- `assets/capcurling.png`: 사용자가 제공한 CapCurling 병뚜껑 아이콘 원본
- `assets/favicon-32.png`: 원본에서 생성한 브라우저 탭 아이콘
- `assets/apple-touch-icon.png`: 원본에서 생성한 iPhone·iPad 홈 화면 바로가기 아이콘
- `assets/icon-192.png`, `assets/icon-512.png`: 원본에서 생성한 Android 및 설치형 웹 앱 아이콘
- `site.webmanifest`: 홈 화면 바로가기 이름, 색상 및 아이콘 설정

AdSense 게시자 `ca-pub-2326184884139629`의 공통 사이트 연결 스크립트가 홈페이지에 적용되어 있습니다. 수동 배너를 표시하려면 AdSense에서 발급한 광고 단위의 `data-ad-slot` 값이 추가로 필요합니다.

병뚜껑은 금속 톱니, 반사광, 브랜드별 인쇄를 SVG로 직접 그린 그래픽이며, 브랜드의 공식 이미지 파일은 사용하지 않습니다.

책상 마찰은 650 units/s², 발사 속도는 125~2000 units/s로 설정되어 강한 초기 움직임 이후 빠르게 감속합니다.
